# ReportNigeria

A web app that reports terrorist attack incidents across Nigeria by collecting inputs from citizens.

## Motivation
Built to keep track of attacks across Nigeria and to develop a prediction system that alerts Nigerians of possible future attacks and terrorist locations.

## Technologies Used
- Python
- Folium
- Streamlit
- Streamlit-Folium

## How to Run
1. Clone the repository
2. Install dependencies:
   ```bash
   pip install folium streamlit streamlit-folium geopandas
   ```
3. Run the app:
   ```bash
   streamlit run map_app.py
   ```
4. Open your browser at `http://localhost:8501`
